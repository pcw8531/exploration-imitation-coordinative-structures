# Scripts of the first earlier study

Scripts 01 to 03 of the repository of Park (2026), Coordinative structures as scale-free networks: Cascade and
percolation dynamics in motor learning with empirical validation, PLoS Comput. Biol.,
https://doi.org/10.1371/journal.pcbi.1014523. They are copied unchanged from
https://github.com/pcw8531/Coordinative-structures-scale-free-networks, archived at
https://doi.org/10.5281/zenodo.20694466.

The notebook EEI_fig2_topology.ipynb holds the same three scripts and runs them, with one line of script 01
adapted to NetworkX 3. The copies here are for comparison.
