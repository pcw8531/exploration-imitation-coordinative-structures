# Data of the second earlier study

This folder holds the seven data files of Park (2026), Average information across a network quantifies
what a coordinative structure achieves in motor control. Code and data. Zenodo.
https://doi.org/10.5281/zenodo.21789488. The header of each file states what it holds and where it comes from.

The notebook EEI_fig3_control_entropy.ipynb reads these files with five code cells of that study, pasted in
the notebook with their code unchanged. The cells load all seven files and check the values of that study
against them. Fig. 3 of this manuscript draws only the cortical structure from them, the matrix
cov_MOTOR_matrix.csv of Weaver et al. (2026). The other structures of Fig. 3 come from the folder `data/fig3_data`.
